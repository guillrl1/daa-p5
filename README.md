# DAA · Práctica 5

Diseño y Análisis de Algoritmos · Grado en Ingeniería Informática · Universidad de La Laguna

Implementación en C++ de una búsqueda local (`src/LocalSearch.cc`) que se ejecuta sobre las instancias `wlp01` a `wlp18` de la carpeta `Instances/`, en formato MiniZinc (`.dzn`).

## Estructura

- `include/`: cabeceras del proyecto
- `src/`: `main.cc` y `LocalSearch.cc`
- `Instances/`: instancias del problema
- `Makefile`: compilación del proyecto

## Compilación

```
make
```

Consulta el `Makefile` para ver los objetivos disponibles.
